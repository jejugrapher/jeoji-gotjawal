# 저지곶자왈 사진 수첩 (Jeoji Gotjawal Photo Notes)

제주 저지곶자왈에서 스마트폰으로 사진을 잘 찍는 요령을 정리한 웹 수첩입니다.
저지리 생태관광마을 「빛이 숲을 떠나는 시간」 프로그램(2026년 9월 28일)의 최경진 작가 강의와 현장 실습 내용을 바탕으로 만들었습니다.
휴대폰과 컴퓨터 화면 모두에 맞게 배치가 바뀝니다.

## 담긴 내용
- **숲에서 나오는 시간**: 날짜를 고르면 저지곶자왈 좌표(북위 33.33°, 동경 126.26°) 기준 일출·일몰, 숲 탐방 권장 시간, 숲에서 나올 시각(일몰 1시간 전), 골든타임을 계산합니다.
- **영상 보고 따라하기**: 맨 위에 「스마트폰 촬영 기법 16가지 한 번에 정리」(https://youtu.be/ZgtNicKeuCM)가 바로 재생됩니다. 16개 기법 카드의 ▶ 버튼을 누르면 영상이 그 기법 부분부터 재생됩니다.
- **1분 준비**, **촬영 포인트 5곳**, **16가지 기법**, **현장 미션 5개**, **숲 예절**
- 페이지 맨 아래에 ① 실내 강의(https://youtu.be/FtWH1kZvKD4), ② 현장 실습(https://youtu.be/PdRsoFzoW-8) 링크
- **사진 보내기**: 방문자가 이름·연락처·이메일과 함께 사진을 보내면 Google Drive 폴더에 모입니다.

> 곶자왈은 해가 지기 전부터 숲 안이 빠르게 어두워집니다. 숲 탐방은 해가 완전히 뜬 뒤 시작하고, 해가 떠 있을 때 반드시 숲을 나오세요.

### 영상을 바꾸려면
`index.html`에서 `ZgtNicKeuCM`(영상 ID)를 새 영상 ID로 바꾸고, 기법 카드 버튼의 `data-t="초"` 값을 새 영상의 해당 시간(초)으로 고칩니다.

## 파일 구성
```
index.html              페이지 전체 (CSS·JS 포함, 외부 의존성은 Google Fonts만)
config.js               사진 받는 주소(Apps Script 웹 앱 URL) 설정
img/                    페이지에 쓰인 사진 7장 (참가자 스마트폰 촬영)
apps-script/Code.gs     사진 받는 창구 (Google Apps Script) — 저장소에는 참고용, 실제로는 Google에 설치
apps-script/appsscript.json   위 스크립트의 설정(권한·웹 앱)
.nojekyll               GitHub Pages가 파일을 가공하지 않게 하는 빈 파일
```

## 1. 사진 받는 창구 설치 (처음 한 번, 약 10분)
GitHub Pages는 파일을 저장할 수 없는 정적 사이트라서, 사진은 Google Apps Script가 대신 받아 Drive에 저장합니다.
스크립트는 **폴더 주인 계정(whipia@gmail.com)** 으로 만들어야 합니다.

1. https://script.google.com 에 접속 → **새 프로젝트** → 프로젝트 이름을 `저지곶자왈 사진 받기`로 바꿉니다.
2. 기본으로 열린 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣습니다.
   - 사진 폴더를 바꾸려면 맨 위 `FOLDER_ID` 값을 Drive 폴더 주소의 `folders/` 뒤 문자열로 바꿉니다.
3. 왼쪽 ⚙ **프로젝트 설정** → "편집기에서 appsscript.json 매니페스트 파일 표시"를 켭니다. 편집기에 생긴 `appsscript.json`을 이 저장소의 `apps-script/appsscript.json` 내용으로 바꿉니다.
4. 위쪽 함수 선택에서 **setup** 을 고르고 **실행** → 권한 요청 창에서 계정을 고르고 허용합니다.
   ("확인되지 않은 앱" 경고가 나오면 **고급 → 저지곶자왈 사진 받기(으)로 이동**을 누릅니다. 본인이 만든 스크립트라서 나오는 안내입니다.)
   - 실행 로그에 사진 폴더 이름과 **접수 목록 시트 주소**가 나오면 성공입니다.
5. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 이 저장소의 `config.js`를 열어 `window.JEOJI_UPLOAD_URL = "";` 따옴표 안에 그 주소를 붙여 넣고 커밋합니다.

스크립트를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 주소는 그대로 유지됩니다.

### 보내 주신 사진과 연락처는 어디에?
- **사진**: `fromPage` 폴더 안에 `날짜_이름_접수번호` 폴더가 생기고 그 안에 저장됩니다.
- **이름·연락처·이메일**: 사진 폴더가 아니라 스크립트 주인의 내 드라이브에 만들어지는 비공개 시트 **「저지곶자왈 사진 접수 목록 (비공개)」** 에 한 줄씩 적힙니다.
- 한 번 보낼 때마다 스크립트 주인에게 알림 메일이 옵니다(`Code.gs`의 `NOTIFY_OWNER`로 끄고 켤 수 있음).

### 꼭 확인할 것: 폴더 공유 설정
지금 `fromPage` 폴더는 **링크가 있는 모든 사용자에게 '편집자'** 로 공유되어 있습니다. 이대로면 링크를 아는 누구나 다른 사람이 보낸 사진과 폴더 이름(보낸 사람 이름)을 보고 지울 수 있습니다.
사진은 스크립트가 주인 권한으로 저장하므로, 폴더 공유를 **제한됨**(또는 링크 있는 사용자 '뷰어')으로 바꿔도 업로드는 그대로 됩니다.

## 2. GitHub Pages로 공개하기
1. 이 폴더의 파일을 저장소 최상위(루트)에 올립니다. (`.nojekyll`처럼 점으로 시작하는 파일도 함께. Finder에서 `Cmd+Shift+.`로 표시)
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 열립니다.

## 개인정보
사진 보내기 양식은 이름·연락처·이메일을 받습니다. 페이지에 수집 항목, 이용 목적(사진 접수 확인·사용 관련 연락), 보유 기간(접수일로부터 1년, 요청 시 즉시 삭제)을 밝히고 필수 동의를 받습니다. 기간이 지나면 접수 목록 시트의 해당 줄과 사진을 지워 주세요.
