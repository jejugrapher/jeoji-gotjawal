# 저지곶자왈 사진 수첩 (Jeoji Gotjawal Photo Notes)

제주 저지곶자왈에서 스마트폰으로 사진을 잘 찍는 요령을 정리한 한 페이지짜리 웹 수첩입니다.
저지리 생태관광마을 「빛이 숲을 떠나는 시간」 프로그램(2026년 9월 28일)의 최경진 작가 강의와 현장 실습 내용을 바탕으로 만들었습니다.

## 담긴 내용
- **숲에서 나오는 시간**: 날짜를 고르면 저지곶자왈 좌표(북위 33.33°, 동경 126.26°) 기준 일출·일몰, 숲 탐방 권장 시간, 숲에서 나올 시각(일몰 1시간 전), 골든타임을 계산합니다.
- **숲에 들어가기 전 1분 준비**: 렌즈 닦기, 4:3 비율, 격자선, 플래시 끄기
- **곶자왈 촬영 포인트 5곳**: 나무 터널 숲길, 잣성 돌담, 작은 동굴 입구, 큰 나무 아래, 고사리 숲 바닥
- **16가지 기법**: 촬영 전 준비와 자세 / 구도와 인물 배치 / 초점과 배경 흐림 / 풍경과 빛 활용
- **현장 미션 5개**와 **숲 예절**

> 곶자왈은 해가 지기 전부터 숲 안이 빠르게 어두워집니다. 숲 탐방은 해가 완전히 뜬 뒤 시작하고, 해가 떠 있을 때 반드시 숲을 나오세요.

## 파일 구성
```
index.html   페이지 전체 (CSS·JS 포함, 외부 의존성은 Google Fonts만)
img/         페이지에 쓰인 사진 7장 (참가자 스마트폰 촬영)
.nojekyll    GitHub Pages가 파일을 가공하지 않고 그대로 배포하도록 하는 빈 파일
```

## GitHub Pages로 공개하기
1. 이 폴더의 파일을 저장소 최상위(루트)에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 열립니다.
